# 2026-09-02 径向 4 阶低强度 Zernike 真实采集重建

## 实验结论

本次将 2026-09-02 的 50 帧 900×900×512 光声采集与指定的径向 4 阶
SLM 相位逐帧配对，完成电机串扰模板去相关、静态 NeuWS 训练、ORIGIN 图像
评价和 Noll 1–15 拟合。正式训练以 300 epoch 为上限，并在 epoch 250 自动
早停，恢复 epoch 170 的最佳 20-epoch 平滑状态。

恢复图像相对 ORIGIN 配准后为 `37.1680 dB / SSIM 0.892063`，自动位移
`[-7, -7]` 像素。恢复相位主要是平滑低阶形态；Noll 1–15 拟合解释
`98.0105%` 的相位方差，包裹残差 RMSE 为 `0.159753 rad`。

真实采集没有系统像差相位真值，因此图像指标可以验证数据和逆问题链路有效，
但不能单独证明恢复相位是唯一物理真值。恢复结果中的 Piston 无物理意义，Tilt
与图像平移存在歧义；拟合生成的 1080 网格 SLM 候选已去除 Noll 1–3，仍只作为
后续光学验证的实验候选，本次没有自动加载到 SLM。

## 图像处理

处理方法与 2026-08-31 同类实验一致：361 点冻结电机串扰模板、每条 A-line
中位数去基线、最大绝对 NCC、阈值 `0.70`、最低拟合峰值 `80 ADC`、有效
非循环重叠区最小二乘幅度拟合、每条 A-line 最多扣除一个模板。随后执行
`max(cleaned - 2048, 0)` 并在完整 512 点深度上做 MIP。未使用逐帧 min-max、
PD、时间门控或空间平滑。

验收结果：

- 测量数组：`(50, 900, 900)`，范围 `11–2047 ADC`，全部有限且非负；
- 帧均值平均：`45.1170 ADC`；
- 帧均值变异系数：`3.78084%`；
- 匹配 A-line 比例平均：`5.71832%`，范围 `5.59198%–5.82580%`；
- 匹配绝对 NCC 中位数的逐帧均值：`0.871933`；
- 训练使用 50 帧共享最大值 `2047 ADC` 归一化。

## 网络训练

- 网络：静态 `StaticDiffuseNet`；
- 输入：50 帧，900×900；
- batch size：10；
- 相位网络层数：4；
- 网络 Zernike 输入特征：Noll 1–28；
- 固定学习率：`1e-3`；随机种子：0；
- 正式上限：300 epoch；
- 早停：warmup 100、window 20、patience 80、min delta `1e-6`；
- 正式训练在 epoch 250 早停，恢复 epoch 170 状态；
- 最佳平滑 MSE：`7.904089e-5`；
- 初始 MSE：`5.935378e-4`；
- 全程最低单 epoch MSE：`7.794887e-5`；
- 停止时观测 MSE：`7.807262e-5`；
- 训练耗时：`666.826 s`；
- 峰值 CUDA 已分配显存：`11,573,257,728 bytes`；
- 最终复场与 `exp(1j*phase)` 一致，无 NaN、OOM 或发散。

> 2026-09-18 勘误：这次训练使用修正前的 early-stopping 实现，当时的
> `best` 同时承担 `min_delta`/patience 参考值，因此这里的“最佳 epoch 170”是
> 旧实现选中并实际恢复的状态，不保证等于所有已计算 smoothed loss 中的绝对最低值。
> 上述输出和指标仍准确描述当时保存的 epoch 170 结果；新实现已把 true historical
> best 与 patience reference 分离。
