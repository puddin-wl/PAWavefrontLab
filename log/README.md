## 记录约定

- 每次实验使用一个日期开头的 Markdown 文件；失败实验也保留并说明失败原因。
- 必须记录数据来源、相位参数、预处理、训练参数、关键指标与限制。
- 大体积结果不提交；日志中写明其本机路径和可复现命令。
- 尚未实施的优化使用“构想”标记，不能与已经验证的结果混写。
