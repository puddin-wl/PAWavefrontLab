# 2026-08-20 低阶 D1-D50 逐帧归一化消融

## 目的

验证原共享最大值归一化是否因 MIP 正噪声底而影响低阶 D1-D50 的 NeuWS 物体—像差分解。

MIP（Maximum Intensity Projection，最大强度投影）将每个 `(x,y)` 位置的 512 个深度/时间采样值取最大值，把 `600×600×512` 压缩为 `600×600`。它能突出峰值信号，也会保留噪声中的偶然最大值，使背景整体高于零。

## 两种归一化

### 原共享最大值

全部 50 帧共用最大值 233：

`y_n = D_n / 233`

网络输入总体范围约为 0.060-1.000，平均值约为 0.187。该方式保留帧间绝对亮度差异，但不去除每帧的正噪声底。

### 本次每帧独立 min-max

每帧分别计算：

`y_n = (D_n - min(D_n)) / (max(D_n) - min(D_n))`

每帧都映射到 `[0,1]`。该方式消除每帧的常数背景和整体增益，同时也会消除帧间总强度差异，并放大各帧噪声和孤立峰值。

实现中新增 `BatchDataset(normalization="per-frame-minmax")` 和命令行参数 `--normalization per-frame-minmax`；默认仍为 `shared-max`，旧实验行为不变。

## 训练参数

除归一化外，与低阶共享最大值实验完全相同：

- D1-D50 与低阶 HW1-HW50；
- 600×600，50 帧；
- 网络 Zernike 特征 28 项；
- 4 层静态相位网络；
- batch size 16；
- 学习率 `1e-3`；
- 最大 1000 epoch；
- 早停 warmup 100、window 20、patience 80、min delta `1e-6`；
- CUDA，随机种子 0。

独立场景名：`real_2026_08_20_loworder_600_per_frame_minmax`。

## 训练结果

- 第 215 epoch 自动早停；
- 最佳状态：第 135 epoch；
- 最佳平滑 MSE：`6.050976e-3`；
- 最小单 epoch MSE：`5.865838e-3`；
- 初始 MSE：`3.793366e-2`；
- 训练时间：246.04 秒；
- 训练稳定，无 OOM、NaN 或发散。

共享最大值版本在第 562 epoch 早停，最佳平滑 MSE 为 `3.930559e-3`。两种输入尺度不同，MSE 绝对值不能直接等价比较；但逐帧版本更早进入波动平台。

## 物体、相位与 origin 预测

记：

- `A = I_est`；
- `B = h(phi_est)`；
- `C = A * B`，即无额外 SLM 相位时的预测 origin。

下表使用每幅图独立 min-max 后的同坐标指标。`I_est` 在计算第六幅诊断图前按训练代码裁剪到 `[0,1]`。

| 归一化 | I_est PSNR | I_est SSIM | C PSNR | C SSIM | 相位标准差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 共享最大值 | 17.4949 dB | 0.147730 | 18.5674 dB | 0.168274 | 1.2552 rad |
| 每帧 min-max | 20.9786 dB | 0.179936 | 20.9782 dB | 0.179961 | 0.09259 rad |

每帧版本的自动配准位移为 `(-1, 7)`，配准 PSNR 为 `21.2355 dB`，SSIM 为 `0.184531`。这些数值说明输出外观更接近 origin，但不能证明卷积前物体正确。

最关键的现象是：

1. 每帧版本的估计相位范围仅为 `-0.6968` 至 `0.0843 rad`，标准差 `0.09259 rad`，接近相位塌缩。
2. 每帧版本中，`I_est` 与卷积后的 `C` 指标几乎完全相同，说明估计 PSF 对输出基本没有作用。
3. 网络主要把 origin 可见结构直接写入 `I_est`，而没有恢复出独立、有效的系统像差。
4. 逐帧归一化使图像外观指标提高，但进一步消除了已知 SLM 调制之间的绝对强度约束，使 A/B 分解更加退化。

## 结论

每帧独立 min-max 对“让重建图看起来像 origin”有帮助，但对当前真正目标——分离卷积前物体与系统像差——没有帮助。它产生了更明显的退化解：`I_est` 直接接近 origin，估计相位接近零，卷积前后几乎不变。

因此本次消融不应作为正式恢复方案。下一步若继续改预处理，应优先考虑保留帧间相对强度的背景估计/噪声底扣除，而不是每帧分别拉满到 `[0,1]`。
