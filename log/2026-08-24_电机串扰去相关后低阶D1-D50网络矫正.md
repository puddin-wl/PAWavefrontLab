# 2026-08-24 电机串扰去相关后低阶 D1-D50 网络矫正

## 目的

将已确认的电机串扰模板去相关方法整合到正式 PA 图像预处理流程，并对
2026-08-20 的低阶 D1-D50 数据重新训练 NeuWS。该实验不使用 PD，也不增加
12–14 μs 时间门控，去相关后仍采用全 512 点深度最大强度投影，以便与原训练
保持单变量对照。

## 输入和配对

- 原始 D 数据：`/mnt/c/neuws_data/raw/2026_0820`，连续 D1-D50。
- origin：`/mnt/e/neuws_data/raw/2026-08-20/origin_20260820-033357_1_600_600_512_PA1.bin`。
- 原数据集：`data/real_2026_08_20_loworder_600`。
- 新数据集：`data/real_2026_08_20_loworder_600_decorrelated`。
- Dn 与 SLM_simN 保持同帧映射；50/50 个 SLM 相位与原数据集逐点一致。
- 所有原始 BIN 只读，程序处理前后检查文件大小与修改时间，未改写原文件。

## 串扰去相关方法

固定使用 2026-08-21 六条典型电机串扰 A-line 拟合出的 361 点模板：

- 模板范围：相对峰值 `-180:180`；
- 每条 A-line 以中位数作为匹配基线；
- 在所有可能中心位置计算归一化互相关；
- 先要求拟合模板峰值不低于 `80 ADC`，再选择绝对 NCC 最大的位置；
- 接受阈值：`|NCC| >= 0.70`；
- 使用有效非循环重叠范围做最小二乘幅度拟合；
- 支持正负极性和记录边缘的截断模板；
- 每条 A-line 最多扣除一个最强匹配分量；
- 扣除后执行 `max(cleaned - 2048, 0)`，再沿 512 点深度取 MIP；
- 不使用 PD、不做时间门控、不做逐帧归一化。

正式实现位于 `preprocessing/pa_denoising.py`，数据集入口为
`tools/prepare_decorrelated_real_dataset.py`。噪声原因审查脚本也改为调用同一
正式实现，避免研究版与数据处理版算法漂移。

模板文件：
`noise_cause_review/results/template_xcorr_v1/fitted_noise_template.csv`。
模板路径、SHA-256、阈值和逐帧统计均记录在新数据集 `manifest.json` 与
`quality_control.json` 中。

## 数据集验收

- 测量形状：`(50, 600, 600)`，`float32`，全部有限；
- 去相关后测量范围：`14–168 ADC`；
- shared-max：`168 ADC`；
- `SLM_rawN.mat`：50 个；`SLM_simN.mat`：50 个；
- 重新解码得到的扣除前 MIP 与原数据集 D1-D50、origin 均逐点一致；
- D1-D50 平均匹配比例：`3.0881%`；
- 各帧匹配比例范围：`2.9928%–3.1619%`；
- 匹配 A-line 的绝对 NCC 中位数逐帧平均：`0.87350`；
- origin 匹配比例：`3.0381%`；
- origin P99.7：`155 -> 102 ADC`；
- D1 完整帧 P99.7：`146 -> 85 ADC`，中位数保持 `45 ADC`；
- 去相关后 D1-D50 帧均值变异系数：`3.4773%`。

质量输出：`quality_control.png`、`quality_trends.png`，以及 origin、D1、D25、
D50 的 NCC、匹配中心和扣除掩膜诊断 TIFF。

## 网络训练配置

与原 2026-08-20 低阶实验一致：

- CUDA：NVIDIA GeForce RTX 5070 Ti；
- 随机种子：0；
- 50 帧，600×600；
- static phase；
- 相位网络 4 层；
- 28 个 Zernike 特征；
- batch size 16；
- 学习率固定 `1e-3`；
- shared-max；
- 最大 1000 epoch；
- 早停：warmup 100、window 20、patience 80、min delta `1e-6`；
- 每 50 epoch 输出一次损失。

## 终止与结论

用户观察到损失在约 `3.25e-3` 附近进入缓慢平台，认为改进不明显，要求停止。
训练在第 350 次正式汇报之后、到达第 400 次汇报之前人工终止；目录中最后的
过程图到约 epoch 375。由于训练未走到正常保存阶段：

- 没有生成 `final/training_summary.json`；
- 没有生成可正式评价的最终重建和恢复相位；
- 没有计算最终 PSNR/SSIM；
- 没有导出新的 SLM 校正相位。

因此本次可以确认：模板去相关稳定去除了约 3.1% 的电机串扰 A-line，并显著
降低高分位孤立峰；但在当前训练观察区间内，网络损失下降很快进入平台。按照
用户判断，本次网络重新矫正记为“去相关有效，但没有带来足够的网络改进，训练
主动终止”。不得把中间过程图作为最终校正相位使用。
