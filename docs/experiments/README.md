# 实验记录

实验记录当前保存在 [`../../log/`](../../log/)；该目录是历史形成的 research
notebook，不是程序运行日志。完整日期索引见
[`../../log/README.md`](../../log/README.md)。

第一轮整理故意不批量移动这些文件，原因是许多记录包含相互引用、当时机器的数据
位置和可复现命令。它们是实验溯源信息，不是正式代码默认配置。失败实验、参数、
指标、结论和未实施构想全部保留。

新增记录继续遵守以下约定：

- 文件名以日期开头；
- 明确成功、失败或“构想”状态；
- 记录数据来源、相位/去噪/训练参数、结果指标、结论与限制；
- 本机绝对路径标注为“当时机器路径（example/provenance）”；
- 原始 BIN 与大体积结果不提交，只记录只读来源和可再生成入口。

后续若迁移到 `docs/experiments/records/`，应单独完成、保留 Git rename 历史，并在
同一阶段修复全部相对链接；不把这一机械移动与算法修改混在一起。
