# B→A 实验：初始像差阶数与网络 Zernike 特征数核对

## 用户意见

1. 本次设置的初始固定像差在图像中不够明显。
2. 初始像差只包含较低阶项（初步估计约第 9 或第 10 项），而 NeuWS 相位网络使用了 28 个 Zernike 输入特征。
3. 如果把网络使用的 Zernike 特征数限制到与初始相位相同的阶数，可能更容易正确恢复真值，避免多余高阶项参与拟合。

## 核对结果

固定真值为：

```text
Phi_true = 0.45*(x^2+y^2) + 0.35*(x^2-y^2) + 0.30*x*(x^2+y^2)
```

按项目实际使用的 AOtools/Noll 基底，真值可由前 **8** 个 Noll 模式表示，而不是必须到第 9 或第 10 项。最小二乘投影结果为：

| 使用模式 | 相位重建 RMSE | RMSE / 真值 RMS |
|---:|---:|---:|
| 前 4 项 | `0.162792 rad` | `54.68%` |
| 前 6 项 | `0.068729 rad` | `23.09%` |
| 前 8 项 | `3.17e-8 rad` | `1.06e-7` |
| 前 10 项 | `3.17e-8 rad` | `1.06e-7` |
| 前 28 项 | `3.17e-8 rad` | `1.06e-7` |

真值 Noll 9–28 的系数能量比例约为 `3.8e-15`，可视为数值零；而本次模型 A 恢复相位中，Noll 9–28 占前 28 项投影系数能量约 `31.1%`。因此，多余的高阶自由度确实被用于产生真值中不存在的相位结构。

初始像差视觉上不明显也符合量化结果：

- 去 piston 后真值 RMS：`0.297714 rad`；
- 峰谷值：`1.494005 rad`；
- 相对于无像差方形瞳的 PSF 峰值比（Strehl 型指标）：`0.91618`；
- “无像差观测”和“只加入 Phi_true 的观测”的相对 L2 差异：`0.01468`；
- 两者 MSE：`2.72e-6`。

也就是说，这组真值只使最终观测变化约 `1.5%`，在血管结构图上肉眼不明显是正常的。

## 判断

“28 项容量过大，可能导致虚假高阶拟合”的判断正确且有数据支持。将 `--zernike_features` 从 28 改为 8，是合理且成本较低的下一组受控 B→A 实验。

但不能预先断言改成 8 就一定恢复正确，原因包括：

1. `zernike_features` 是 `StaticDiffuseNet.g_g` 相位/振幅 MLP 的逐像素输入特征数，并非严格的线性 Zernike 系数模型。即使只输入前 8 项，多层非线性 MLP 仍可生成不属于前 8 项线性张成空间的结构。
2. 模型 A 与生成数据的模型 B 仍有物理采样、区域积分核和边界处理失配。
3. 模型 A 仍可同时调整物体和非均匀复瞳振幅；相位阶数降低后，失配可能继续转移到这两个补偿通道。
4. 当前真值造成的观测变化只有约 `1.5%`，可辨识信号较弱。

## 建议的最小验证

保持同一份模型 B 数据、同一随机种子、同一 `object_mmes` 和全部优化参数不变，只把：

```text
--zernike_features 28
```

改成：

```text
--zernike_features 8
```

然后比较相位 RMSE/相关系数、Noll 9–28 的投影能量、复瞳振幅变异系数、物体误差和 50 帧观测 Loss。也可增加 `10` 作为编号容错对照，但从当前真值投影看，8 已足够。

如果目标是从数学上严格禁止高阶相位，则需要把相位表示改成直接的线性系数：

```text
Phi = sum(c_j * Z_j)
```

这属于网络参数化改变，不等同于单纯设置 `zernike_features=8`，本次尚未实施。
