# OR-PAM 物理前向模型 B

本文档对应独立实现 `optics/orpam_model_b.py`。它不替换现有 NeuWS 训练入口，也不修改
`recon_exp_data.py`。模型边界是：SLM 与入瞳等效共面、理想薄透镜后焦面、默认方形均匀
照明，并可选用按物理直径定义的均匀硬边圆孔；不包含约 1 m 自由空间传播、反射/分束元件、
额外离焦传播、声传播或更密的硬件扫描。
真实相位文件中已有的离焦等相位项原样参与计算。

## 1. 现有模型 A 的实际链路

`BatchDataset` 从 `SLM_simN.mat:proj_sim` 读取相位，默认构造
`X_i = M exp(-i Gamma_i)`。`StaticDiffuseNet` 同时预测物体 `O` 和自由复瞳
`G = A exp(+i Phi)`，其中振幅 `A` 也由网络输出，并非固定为一。继承的前向过程计算
`|FFT(G X_i)|^2`、按离散像素和归一化、翻转 PSF，再用双倍补零 FFT 做同尺寸卷积。
`object_mmes` 只替换物体表示，仍保留该光学链路和原像差 MLP。训练入口把预测图像与真实图像
做 MSE，并按所选 MMES 分支叠加自编码器正则。

模型 A 的主要物理缺口是把瞳面、PSF 和 600×600 测量数组直接绑定；波长、焦距、SLM
像元间距与 5 um 扫描步长没有形成坐标映射。模型 B 保留平移不变线性算子，但重新建立这层
物理映射。

## 2. 参数、相位和坐标约定

默认参数如下：

| 参数 | 数值 |
| --- | --- |
| 波长 | 532 nm |
| 焦距 | 50 mm |
| SLM 全尺寸/使用区 | 1920×1080 / 中央 1080×1080 |
| SLM 像元间距 | 6.4 um |
| 方形使用宽度 | 6.912 mm |
| 标称 NA / 实际光束直径 | 0.1 / 约 6.5–6.9 mm（默认方孔；可显式选择等直径硬边圆孔） |
| 样品与扫描 | 二维碳纤维吸收，600×600，5 um 步长 |
| FFT 网格 | 4320×4320 |
| 焦平面采样 | 0.9620949 um |
| 物体/扫描步长 | 5 um |
| 默认求积 | 12×12 Gauss-Legendre |
| 默认核支持 | 半径 32 个扫描单元，即 65×65 |

复瞳为

`P_i(u,v) = M(u,v) exp(+i Phi(u,v)) exp(-i Gamma_i(u,v))`。

默认 `M=1`，保持原有方形均匀瞳行为。可选圆孔按 1080 网格的物理像元中心和给定直径
生成二值掩膜，圆内为一、圆外为零，在中心补零和 FFT 之前乘到复瞳上。PSF 仍归一化为
单位物理面积积分，因此圆孔模式没有模拟孔径截取造成的绝对光功率下降。

负号来自仓库和相位库 manifest 的 `exp(-1j * proj_sim)` 约定。MAT 中的硬件相位以弧度
保存；PNG 只用于核对包裹值和空间姿态，不能直接当弧度，也没有应用硬件 LUT。

PyTorch 张量倒数第二维是物理 `y`/row，最后一维是物理 `x`/column。显式对称补零后，
先 `ifftshift`、做二维 FFT、再 `fftshift`。偶数 FFT 网格的零坐标位于索引 `N_fft//2`，

`x[j] = (j - N_fft//2) dx_focus`，

`dx_focus = wavelength * focal_length / (N_fft * slm_pixel_pitch)`。

600×600 物体的全局物理中心在中央四个单元之间；单元中心可写成
`(index - 299.5) * 5 um`。前向式只依赖单元索引差，因此核自身的零偏移位于奇数核的中央
元素。

## 3. FFT 标度和归一化

省略不影响强度的全局相位后，离散连续傅里叶近似为

`U_f = FFT(P) * p^2 / (wavelength * focal_length)`。

模块同时保留未归一化强度及其物理面积积分，用于能量诊断。交给等效核的 PSF 按

`sum(h) * dx_focus^2 = 1`

归一化，因此 `h` 的量纲为 `m^-2`。这与模型 A 的“离散像素和等于一”不同。没有逐帧
min-max；总体光声比例仍应由后续共享标度或物体强度承担。

## 4. 5 um 分块常数物体和等效核

物体参数 `O[m,n]` 表示对应 5 um×5 um 方块内恒定的吸收系数，不表示扫描仪对该方块做
面积积分。把该连续物体表示代入点扫描测量后，row/column 偏移为 `k,l` 的核是

`K[k,l] = integral integral h(k*Delta+u, l*Delta+v) du dv`，

其中 `u,v` 均在 `[-Delta/2, Delta/2]`，`Delta=5 um`。实现按真实物理坐标把求积节点映射
到 FFT 网格，以 `grid_sample(..., align_corners=True)` 双线性读取 PSF，并做二维
Gauss-Legendre 加权。节点和权重被缓存；依赖像差的 PSF 和核没有 `detach()`。

最终前向式为

`I[p,q] = sum O[p+k,q+l] K[k,l]`。

这正是 PyTorch `conv2d` 的互相关约定，因此模型 B 不翻转核。有限物体外采用零延拓，边缘
响应会低于内部均匀区。非对称核、单点物体和显式逐项求和测试共同防止方向被误改。

## 5. 真实相位和编号

`HardwareSLMPhaseLibrary` 强制读取双网格 manifest 和
`hardware_1080/mat/SLM_hwN.mat:phase_hw`，并检查：

- 50 帧编号连续且硬件形状为 1080×1080；
- 单位为弧度、两个网格共用同一组系数、相位符号为负；
- 可选逐帧验证 MAT 与包裹 PNG 的数值和姿态；
- 实验 manifest 的 `frame_index` 必须严格为 1…50；
- 实验的 `phase_source_directory` 必须指向同一双网格库的 `model_600/mat`。

本机 2026-10-13 数据已经验证为
`s01...s50 -> frame 1...50 -> SLM_sim1...50 -> SLM_hw1...50`。第 1、50 帧 MAT/PNG
最大圆周相位误差均小于 `5e-5 rad`，符合 uint16 量化误差。加载器不会从 600 网格 resize，
也不会重新生成随机相位。

## 6. 运行方式

运行真实第 1 帧，并同时校验实验编号和 PNG：

```bash
/home/xiangwan/miniconda3/envs/neuws/bin/python tools/run_orpam_model_b.py \
  --frames 1 --fft-size 4320 --kernel-radius 32 --quadrature-order 12 \
  --measurement-dir data/2026-10-13_object_mmes --validate-png \
  --output-dir outputs/orpam_model_b
```

`--frames 1,2,5-8` 支持多帧，但程序逐帧做大 FFT，避免默认把 50 帧同时放入内存或显存。
可用 `--object` 提供 600×600 的 NPY/MAT/TIFF，用 `--aberration` 提供 1080×1080 的人工或
已知像差；没有提供时分别使用确定性的纤维测试物体和零像差。每帧输出压缩 NPZ（PSF、物理
坐标、等效核、模拟图像和物体）、模拟 TIFF，以及记录全部参数和能量诊断的 JSON。

模型 A/B 受控比较：

```bash
/home/xiangwan/miniconda3/envs/neuws/bin/python tools/compare_orpam_models.py \
  --frame 1 --fft-size 4320 --kernel-radius 32 --quadrature-order 12 \
  --device cpu --output-dir outputs/orpam_model_a_b_4320
```

比较脚本使用同一系数分别生成的真实 600 和 1080 相位，并把两边未知像差设为零、振幅设为
均匀一，以隔离物理采样差异。它明确不把这个受控的单位振幅模型 A 当成训练后的
`StaticDiffuseNet`；后者还有自由振幅表示。

运行测试：

```bash
CUDA_VISIBLE_DEVICES='' /home/xiangwan/miniconda3/envs/neuws/bin/python -m pytest -q \
  tests/test_orpam_model_b.py
```

## 7. 数值验证和实际 A/B 数据

自动化测试覆盖方孔 sinc-squared 主瓣及物理 FWHM、FFT 补零收敛、区域积分、单物体单元、
非对称方向、显式倾斜焦斑与点扫描反向位移、均匀物体、支持截断、Autograd/中心差分、
600×600 输出和真实相位编号，共 12 项。

真实第 1 帧、零系统像差、同一纤维测试物体的 4320 结果：

| 指标 | 模型 A | 模型 B |
| --- | ---: | ---: |
| PSF 网格 | 600×600，无物理焦面步长 | 4320×4320，0.9621 um |
| 理想 PSF 峰值 | 1（离散和归一化） | 6.75218e10 m^-2 |
| 随机相位 PSF 峰值 | 0.0987463 | 6.87763e9 m^-2 |
| 随机相位相对理想 PSF 的归一化 L2 差异 | 1.38720 | 1.26086 |
| 理想方孔首零/FWHM | 无可检验物理映射 | 3.8484/3.4093 um |
| 65×65 核保留能量 | 不适用 | 0.995142 |
| 模拟图峰值 | 0.711460 | 0.783134 |

两张最终模拟图各自做 L2 范数归一化后的差异为 `0.311744`。模型 B 随机 PSF 的质心为
`(-0.173 um row, +1.020 um column)`，RMS 半径为 `48.808 um`。这里的差异同时包含正确的
物理采样/区域积分和模型 A 的旧数组离散方式，不包含自由瞳振幅带来的差异。

第 1 帧的数值收敛结果如下：

| N_fft | dx_focus | 65×65 核相对 8640/4320 参考的变化 |
| ---: | ---: | ---: |
| 1080 | 3.848 um | 相对 4320：21.17% |
| 2160 | 1.924 um | 相对 4320：3.00% |
| 4320 | 0.962 um | 相对 8640：0.696% |
| 8640 | 0.481 um | 参考检查 |

因此 4320 适合作为第一版速度/精度折中，但尚不能称为完全收敛。8640 的单帧无梯度检查峰值
常驻内存约 3.12 GiB；保存完整 A/B 数组的 4320 CPU 运行约 7.9 s，峰值约 2.03 GiB。默认
保持 4320，精度敏感的最终报告应抽样复核 8640，而不是对 50 帧同时使用 8640。

4320、12 阶求积时，第 1 帧核支持的保留能量为：17×17 `97.943%`、33×33 `99.026%`、
65×65 `99.514%`、129×129 `99.757%`、193×193 `99.840%`。默认 65×65 的约 0.486%
截断误差已被 JSON 明确记录；不同随机帧仍需分别检查，不能假定这一数值对全部 50 帧相同。

## 8. 尚未解决的问题

- 相位负号和图像姿态已与仓库、MAT、PNG、实验编号一致，但仍缺少独立硬件标定靶对绝对
  相位符号和实验坐标方向的最终确认。
- PNG 未应用器件 LUT；模型读取的是实验设计的 MAT 弧度相位，不能证明硬件实际调制相位与
  设计值完全一致。
- 方形 6.912 mm 均匀瞳是受控基准。实际约 6.5–6.9 mm 入射光束、近圆形光阑和空间振幅
  非均匀性尚未建模；标称 NA=0.1 也不等同于本方孔轴向有效 NA。
- 5 um 分块常数物体是显式近似；亚 5 um 碳纤维会产生物体表示误差。
- 有限物体采用零边界；真实扫描区外吸收未知，训练对比时应单独分析边缘残差。
- 尚未加入 SLM 到透镜传播、额外离焦、声学响应，也未接入正式训练 pipeline。
- 4320 与 8640 的单帧核仍有约 0.7% 相对差异；50 帧已在 2160 FFT 下完成初步统计，并对
  最小、中位、最大差异帧做了 1080/2160/4320 收敛复核，但未对全部 50 帧做 4320/8640。

完整的 50 帧结果、受控因素分解和可视化见
[模型 B 验证与 A/B 系统性对比](orpam_model_b_validation.md)。
